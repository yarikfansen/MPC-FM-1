# FM-1 custom — карта меню и ручек

Сборка: `custom/mixer-home` (09.11, после ALPHA 6b087a3), на синте ещё не проверена.
Обозначения: **SELECT**, **ALGORITHM**, **PRESETS** — три верхних энкодера; **K1–K4** — четыре ручки под экраном.
⚠ — известная ловушка или ещё не решённый вопрос.

## 1. Кнопки (действуют везде)

| Кнопка | Нажатие | Удержание / сочетание |
|---|---|---|
| HOME | на уровень вверх (подстраница → её страница → микшер) | удержание 0,6 с: SCOPE (ещё раз — микшер) · HOME+SAVE: отмена/повтор · HOME+PLAY: стоп всех нот · HOME+SEQ: tap tempo · HOME+GLO: Bluetooth |
| PLAY | играть → пауза → продолжить с того же места | удержание: с начала |
| REC | запись вкл/выкл (во время игры — живая, на стопе — по шагам) | на микшере: REC + SELECT двигает курсор записи |
| SEQ | сетка шагов (SEQ 1/8) | на сетке: нажатие — страница 1 STEP (переработка SEQ, C1), на страницах 1–3 — назад в сетку; удержание — CHAIN · SEQ+EDIT: меню SEL |
| EDIT | звук дорожки (DX7: окно EDIT, остальные: страницы движка) | удержание 0,6 с: подробный редактор (DX7: FM LAB 1–11) · на сетке SEQ и страницах 1–3: тоже звук дорожки, второй EDIT — назад на ту же страницу SEQ · EDIT+REC на DX7: имя звука (NAME) |
| ENV | огибающая DX7 (у других движков не работает) | |
| LFO | LFO 1 → LFO 2 → выход | |

| FX | TRACK FX → MASTER FX → закрыть | удержание: сразу MASTER FX |

## 2. Клавиатура

- Везде, кроме перечисленного ниже: играет ноты выбранной дорожки (с ARP — подаёт ноты в арпеджио).
- SEQ 1/8 (сетка): клавиша звучит и ставит свою ноту в выбранный шаг (с REC и без); та же нота ещё раз — стирает. С включённым ARP (мелодическая дорожка, REC выкл.) клавиши только подают ноты в арпеджио: в сетку ничего не пишется; на стопе арпеджио играет на месте, с PLAY — вместе с секвенсором.
- SEQ STEP: клавиши звучат и пишут аккорд в выбранный шаг (только мелодические дорожки; до 8 нот; клавиша, добавленная к зажатым, дополняет аккорд). OCT −/+ — октава.
- SEQ RHYTHM/REC и TRACK ROLE: 16 белых клавиш — это ряд из 16 шагов сетки, клавиша включает/выключает шаг.
- Мягкое свечение (STEP и ARP): клавиши аккорда горят ярко, остальные ноты тональности — тускло (тональность — GLOBAL KEY; в AUTO — по первому аккорду после включения или загрузки проекта).
- DX7 FM LAB: подписанные чёрные клавиши выбирают OP1–6 / Pitch / Global / Mono / Poly.
- ⚠ Если в GLOBAL → MIDI SYNC ручка K1 (LOCAL) = OFF, клавиши и ARP молчат, а секвенсер играет. Теперь при нажатии клавиши синт пишет «LOCAL OFF: MIDI SYNC K1».

## 3. Микшер (главный экран, TRACKS)

| | |
|---|---|
| SELECT | дорожка 1–8 |
| PRESETS | движок дорожки (открывает плитки ENGINES; HOME закрывает) |
| ALGORITHM | звук (пресет) движка |
| K1 VOLUME | громкость дорожки |
| K2 BRIGHT | яркость (DX7, 303, PLUCK, MICRO D); на 808 — TONE (тон бочки и малого вместе); на PSG и SAMPLER — «--» (нет такого параметра) |
| K3 PAN | **L / C / R** — переключение канала (на MICRO D — всегда; на других — где движок понимает) |
| K4 STATE | ON → SOLO → MUTE (по кругу) |

ENGINES: 8 плиток (DX7, 303, 808, PSG, PLUCK, SAMPLER, MICRO D, BINAURAL); смена барабанного ↔ мелодического движка спрашивает подтверждение (SAVE = ОК, HOME = отмена). MICRO D — не больше двух дорожек.

## 4. Секвенсер (SEQ)

**1/8 BASIC — сетка.** SELECT — шаг по строке, ALGORITHM — строки, PRESETS — длина дорожки 16/32/48/64. При включённом REC курсор двигается, запись не выключается (запись по шагам идёт с нового места).
K1 VELOCITY · K2 LENGTH (1/16 … целый шаг, дальше нота тянется на следующие шаги: «N STEPS», до длины секвенции, останавливается перед следующим занятым шагом; SAMPLER: длина пэда; 808: «--») · K3 PROB (1/8 … всегда) · K4 NOTE (на 808/SAMPLER — пэд). Удержанная в живой записи (REC) нота тоже пишется до длины секвенции (было 16 шагов).

Страницы SEQ (переработка C1–C3): нажатие SEQ на сетке — страница 1, SELECT листает 1 STEP → 2 VARIATION → 3 TRACK (упоры на краях), SEQ — назад в сетку, **ALGORITHM выбирает шаг**, **PRESETS — ряд из 16 шагов**. VARS, LOCK/VALUE и TIE-редактор убраны; SWING — только на ARP 2; CLICK и COUNT IN — в GLOBAL › CLICK; длина секвенции — PRESETS на сетке.

| Страница | K1 | K2 | K3 | K4 |
|---|---|---|---|---|
| 1 STEP | CHORD | RATCH (OFF/2X/3X/4X — дробление шага; только в памяти, теряется при сохранении/перезагрузке) | SPACE (через сколько шагов копия) | REPEAT (сколько копий; копии затухают как дилей, занятые шаги пропускаются, в конце — по кругу) |
| 2 VARIATION | MUTATE (в тональности) | HUMAN | TRANSPOSE (вся дорожка) | CHANCE (OFF · HOUSE 1–3 · TECHNO 1–3 · TRANCE 1–3 · DNB 1–3) |
| 3 TRACK | ROLE (NORMAL/PLAY/OFF) | IN CH | FOLLOW (только MICRO D) | — |

STEP: «STEP n», 16 шагов ряда как на сетке, ноты аккорда, крупно — шаг с дроблением. VARIATION: картинка из 16 клеток — ритм CHANCE (OFF = все 16 горят) и его имя; на ручке — HS1 … DB3. CHANCE не меняет записанный паттерн: заглушённые шаги просто не играют (и их RATCH тоже), длинная нота следует за своим началом. MUTATE: прыжки на октаву/квинту, потом нота сдвигается в ближайшую ступень лада (сначала вверх); KEY = AUTO, пока аккорда не было, — только октавы. Старый проект: CHANCE в процентах загружается как OFF. Аккорд шага справа вверху на всех трёх страницах.

**CHAIN (удержание SEQ):** SELECT — столбец, K1 — строка, K2 PROJECT (проект в ячейке), K3 REPEAT, K4 CHAIN вкл/выкл, SAVE — перейти сюда сейчас.

## 5. ARP и LFO

| Страница | K1 | K2 | K3 | K4 | Ещё |
|---|---|---|---|---|---|
| ARP 1 | RATE | GATE | LATCH | ARP вкл/выкл | PRESETS — режим, ALGORITHM — октавы; справа вверху — аккорд зажатых клавиш (вместо ON) |
| ARP 2 (случайность) | MUTATE (в тональности, как в SEQ) | SWING | VAR | CHANCE | то же |

**Запись арпеджио в шаги (11.11):** ARP вкл. + REC. Во время игры каждая нота арпеджио ложится в шаг под бегущим курсором, а если нота сдвинута (свинг, RATE между шагами) — в ближайший шаг; две ноты в одном шаге = аккорд. На стопе с REC арпеджио только звучит (курсор стоит, ничего не пишется); PLAY — запись идёт дальше, арпеджио продолжает со следующей ноты, а не с первой. ⚠ UNDO после такой записи откатывает только до последнего PLAY, перед которым запись стояла на стопе с ARP. Конец REC выключает арпеджио.
| LFO 1 / LFO 2 | TARGET | RATE | DEPTH | WAVE | LFO 1/2 — кнопкой LFO или SELECT (вправо LFO 2, влево LFO 1) |

## 6. Эффекты

**TRACK FX:** K1 REV SEND · K2 DLY SEND · K3 TRK VOL · K4 ALL RET.
**SHARED FX** (общие реверб и дилей): K1 REV TIME · K2 DLY TIME · K3 FEEDBACK · K4 RETURN.
**MASTER FX** — SELECT выбирает эффект:

| Эффект | K1 | K2 | K3 | K4 |
|---|---|---|---|---|
| FILTER (ACID, SEM, LADDER, COMB, DJ) | TYPE | CUTOFF | RESO | MIX |
| DRIVE (SOFT, HARD, FOLD, CRUSH) | TYPE | DRIVE | TONE | MIX |
| CHORUS (CHORUS, FLANGE) | TYPE | RATE | DEPTH | MIX |
| PHASER (4/6/8 ST) | STAGES | RATE | FEEDBK | MIX |
| RING (8 волн) | WAVE | FREQ | SPREAD | MIX |
| REVERB (ROOM, HALL, PLATE) | TYPE | DECAY | PREDELAY | MIX |
| EQ | MID HZ | LOW | MID | HIGH |
| COMP | THRESH | RATIO | SPEED | MIX |
| DELAY / SENDS | общий дилей и посылы (как SHARED FX) | | | |

MIX = 0 — эффект выключен. При перегрузке процессора мастер-эффекты отключаются примерно на 1 с («CPU FULL: MASTER FX OFF»), синт не перезагружается.

## 7. Звук дорожки (EDIT)

- **DX7:** EDIT — окно TONE / ENV (SELECT переключает); удержание EDIT — FM LAB 1–11 (TUNE/LVL, VOICE RATES, VOICE LEVELS, SENS/OSC, SCALING, CURVES, PITCH RATES, PITCH LEVELS, COMMON, LFO, LFO MOD); ENV — огибающая K1–K4.
- **303, PSG, PLUCK:** страницы по 4 параметра движка, SELECT листает.
- **303 MONO / POLY:** на странице EDIT дорожки 303 9-я чёрная клавиша слева = MONO (один голос), 10-я = POLY (до 4 голосов); горит та, что включена сейчас. MONO примерно вдвое дешевле для процессора (проверено 10.11). Код: `app/screen.c:137`, 7251–7255.
- **808, SAMPLER:** SELECT — пэд, ALGORITHM — страницы, K1–K4 — параметры пэда (Level, Tune, Length, Choke…).
- **MICRO D:** 5 страниц: SAW SHARK SQR TRI · DETUNE NOISE GLIDE VCA · CUTOFF RESO CONTOUR DRIVE · ATTACK DECAY SUSTAIN RETRIG · RATE WAVE AMOUNT MODE.
- **SAMPLER REC** (REC в редакторе сэмплера): K1 SOURCE (USB/BT/MIX) · K2 THRESH · K3 LENGTH · K4 MONITOR. **CHOP:** K1 START · K2 SLICES · K3 MODE; SAVE — сохранить.

## 9. SEL и сохранение

**SEL:** три ряда — STEP (COPY, PASTE, CLEAR) · TRACK (COPY, PASTE, CLEAR, UNDO) · SOUND (COPY, PASTE, ROLE, NAME). Ручку вправо — выбрать, SAVE — выполнить; то, что стирает данные, сначала спрашивает REPLACE DATA? (SAVE ещё раз = да, HOME = нет).
**SAVE (проект):** SELECT или PRESETS — ячейка, ALGORITHM — позиция в имени, K1 0-9 · K2 A-M · K3 N-Z · K4 SAVE/LOAD; кнопка SAVE выполняет (LOAD — вторым нажатием). Заголовок — SAVE; что лежит в выбранной ячейке (имя / EMPTY / READ ERROR) — крупно под ним, слева от плашки SLOT; редактируемое имя — в окне.
**NAME (имя звука DX7):** K1 0-9 · K2 A-M · K3 N-Z; SAVE = ОК.

## 10. Что запутано в MIDI сейчас (почему «не работает»)

- Было: одни и те же настройки в трёх местах. Теперь (код 09.11, ещё не на синтезаторе) MIDI только в GLOBAL › MIDI; часы — там же и BT K4.
- По умолчанию SEQ/ARP = LOCAL у каждой дорожки: ноты секвенсора наружу **не уходят**. Наружу уходят только клавиши (KEY OUT), и только в порты из OUT PORT.
- LOCAL — в GLOBAL › MIDI › MIDI SYNC (K1).
- Ваше предложение — одно меню MIDI: K1 порт (USB / DIN / BLE) · K2 канал IN · K3 канал OUT · K4 ведущий / ведомый. Сначала макет, потом код.
