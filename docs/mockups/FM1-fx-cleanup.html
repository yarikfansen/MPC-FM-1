1. MASTER FX: анимированные страницы → статичные картинки

Картинка перерисовывается только при повороте ручки. CHORUS — две копии волны со сдвигом (DEPTH = сдвиг, RATE = число волн), PHASER — провалы (FEEDBK = глубина), RING — волна, «порезанная» второй (FREQ = частота реза), REVERB — гладкий хвост (DECAY = длина, PREDELAY = пауза перед ним).

СЕЙЧАС · RING MOD: волна бежит 10 к/с
ПРЕДЛОЖЕНИЕ · RING MOD: застывший кадр, FREQ меняет частоту реза
