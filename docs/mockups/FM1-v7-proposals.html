1. 303 EDIT · стр. FILTER (ENV убрана)

Одна картинка на все 4 ручки — кривая фильтра без разных анимаций. Крутим ручку — горит её часть: CUTOFF — точка среза; RESO — пик; ENVMOD — пунктирная кривая «куда огибающая толкает срез» и стрелка вправо; DECAY — стрелка назад. Остальное серое.

2. 808 EDIT

Имя барабана крупно по центру. 11 барабанов + набор (KIT). Внизу — удар выбранного барабана.

3. Микшер: иконка движка + звук вверху

PRESETS меняет движок (иконка и подпись), ALGORITHM — звук. Все 8 дорожек на месте. Автосохранение через 3 с.

4a. SEL — список

Список объектов (STEP / PAGE / TRACK / SOUND); внизу кнобы-действия, значение — над чем действие.

4b. SEL — барабан

Объекты как вращающийся барабан, SELECT крутит; внизу кнобы-действия для выбранного объекта.

5. SEQ: REC слева, CHAIN справа

Два одинаковых блока «надпись + лампа» по краям строки, как блоки в ARP.

7. SAVE / LOAD проекта

K1 — слот, K4 — SAVE / LOAD, кнопка SAVE — выполнить. Загрузка чужого слота спрашивает второй SAVE.

8. 303 OSC/LEVEL (стр. 2)

ACCENT — высота обычной и акцентной ноты; WAVE — пила; TUNE — стрелка на шкале; VOLUME — высота волны.

9. 303 DRIVE/SLIDE (стр. 3)

DRIVE — срезанная волна; DRIVE TYPE — три кривые, выбранная подсвечена; SLIDE — глайд между нотами; ACC DEC — акцентный горб и спад.

10. PSG (1 страница)

MODE — квадрат с шумом (MIX); NOISE — шумовые штрихи; TUNE — стрелка полутонов; RELEASE — хвост после отпускания.

11. PLUCK (1 страница)

DECAY — струна затухает; BRIGHT — столбики гармоник; TUNE — стрелка; RELEASE — хвост после отпускания клавиши.

12. SAMPLER EDIT 1/2

Имя пэда крупно, 8 пэдов в ряд (выбранный розовый). LEVEL — высота формы волны на фоне полной шкалы; TUNE — стрелка на линейке; LENGTH — после точки обрезки волна тусклая; CHOKE — 4 группы, одна горит, линия «один пэд гасит другой».

13. SAMPLER EDIT 2/2

VARIATION — 4 удара с разной высотой/стартом, выбранный горит; VEL LPF — тихий удар темнее и глаже громкого. Кнобов 3 и 4 нет, поэтому два экрана.

21. Новые функции

21a. GLOBAL LFO 1/2

LFO 1 | LFO 2 — вкладки в рамках, по центру; переключает PRESETS (подсказки нет). В окне как у эффекта: мелко частота и волна, крупно (26) цель, полоса глубины от центра, живая волна со звездой. Кнобы: TARGET, RATE, DEPTH, WAVE. Слева лампа LFO ON.

21b. SEQ — страница VARIATION

Слова VARIATION нет: полоса из 4 имён как на 20b, имя выбранного крупно (26) в окне. MUTATE — часть нот сдвинута вверх/вниз за петлю, призрак старой позиции рамкой; HUMAN — шаги чуть съехали с линий сетки; RATCHET — один шаг делится на 1/2/3/4 удара, выбранный (3) горит; CHANCE — часть шагов бледные (пропускаются).

21c. CHAIN с повторами

Поле 4x4: крупно номер слота проекта, в правом нижнем углу счётчик повторов (x1 тусклый). Белая пульсирующая рамка (к центру гаснет) — выбранное поле, красная толстая — играет сейчас. Кнобы: FIELD, PROJECT, REPEAT (x1..x16), CHAIN ON/OFF.

21d. SAMPLER — запись

Ряд пэдов, большой индикатор входного уровня с порогом THRESH (метка). Над рамкой: лампа источника USB/BT, длина «1.2 / 2.3 S» с полосой времени, лампа MON. Слева — ожидание звука (уровень ниже порога), справа — идёт запись.

21e. SAMPLER — нарезка

После записи: волна с 8 метками, номера 1..8, все 8 пэдов горят. Выбранный срез (PAD) подсвечен, его начало (START) двигается стрелками. Режим TRANSIENT — метки по пикам. Кнобы: PAD, START, SLICES 4/8/16, MODE EVEN/TRANSIENT (K1 всегда — что правим, остальные — его параметры).
