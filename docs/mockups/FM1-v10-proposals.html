FM-1 v10 — эскизы (код не трогаю до «да»)

Длинные ноты на сетке, новая страница SAVE, свои цвета у движков, страница INFO, живой фон в «Матрице». Уже сделано без эскиза (ты попросил прямо): удержание HOME открывает осциллограф, ещё одно удержание — микшер.

1. Длинная нота / аккорд — «хвост кометы»

сетка: нота держится 5 шагов, аккорд — 3
STEP EDIT первого шага — что записано
  • Записывая вживую, отпускание клавиши тоже ловим: держал меньше шага → GATE в % шага; дольше → первый шаг GATE 100 % + TIE, следующие шаги — продолжение (TIE), последний — сколько додержал.
  • На сетке: первый шаг — обычная клетка, от её центра тянется линия-хвост через все шаги звучания, к концу тускнеет. Аккорд — толстая линия (по числу нот).
  • STEP EDIT показывает честно: LENGTH «5 ШАГОВ», TIE ON; ручкой LENGTH можно удлинить/укоротить — хвост меняется сразу.

2. SAVE — главное крупно, симметрично

  • По центру крупно имя проекта, буква под курсором пульсирует.
  • Над ним — номер слота крупно; 16 слотов — два ровных ряда по 8 по центру (жёлтый — этот проект, золотой — занят, контур — пусто).
  • Снизу: розовая SAVE, «to», зелёная галочка — по центру.

3. Цвета движков

  • У каждого движка свой цвет значка: DX7 — небесный, 303 — кислотно-зелёный, 808 — оранжевый, PSG — фиолетовый, PLUCK — янтарный, SAMPLER — бирюзовый, MICRO D — медно-оранжевый.
  • Цвета не совпадают с цветами ручек, чтобы не путать.

4. INFO

  • GLOBAL → INFO: версия и сборка, на чём основано, память и процессор, батарея, ссылки (GitHub, Ko-fi). Всё по центру, главное крупно.

5. Матрица: живой фон

  • Тусклый «цифровой дождь» медленно течёт за окнами; яркость низкая, надписи всегда поверх на чёрном.
  • Только в теме «Матрица», можно выключить в GLOBAL.
