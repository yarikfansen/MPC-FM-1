FM-1 — приложение для телефона (эскизы)

Черновик к согласованию. Веб-приложение (PWA) в Chrome на the Android phone, кабель USB-C → FM-1. Тот же стиль, что у экранов v6: тёмный фон, Barlow, цвета кнобов K1 розовый, K2 зелёный, K3 жёлтый, K4 бирюзовый, котики-операторы. Номера экранов — для ответа в чате.

  • Сверху FM LAB: шесть котиков по схеме алгоритма, тап = выбрать оператор.
  • Четыре больших кноба K1–K4: тянуть пальцем вверх/вниз, двойной тап = ввод числа.
  • Страницы: ОБЩЕЕ (CHOIR, FB, транспонирование, имя), OP1–6, EG, LFO, PITCH.
  • Звук при правке: на синт уходит голос целиком (стандартный DX7 SysEx, без записи во флеш), без синта — тот же движок DX7 в телефоне.
  • Внизу мини-клавиатура для пробы. СОХРАНИТЬ = запись слота в банк.

4 · Клавиатура (ландшафт, на весь экран)

→ FM-1 · дорожка 1A04 · E.PIANO 1◀ OCT 3 ▶HOLD
  • Мультитач, 2 октавы; свайп по верхней полосе = сдвиг октавы.
  • Сила нажатия по высоте: тап у верхнего края — тихо, у нижнего — громко (полоска справа подсказывает).
  • Слева две полосы: PITCH (пружинит в центр) и MOD.
  • Куда играет: FM-1 по USB (канал выбранной дорожки) или, без синта, встроенный движок телефона.
