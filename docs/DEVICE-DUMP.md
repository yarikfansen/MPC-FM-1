# FM-1: снять копию памяти (только чтение) — план к приезду Transporter

Статус 22.10.2026: второй синт исправен, официальная V15. Transporter (Seeed XIAO RP2040) едет.
Сведения собраны по README сообщества (не проверены на нашем синте). Каждый шаг с устройством — только после «да» пользователя.

## Что понадобится
- Seeed XIAO RP2040 (именно RP2040; RP2350 не работает).
- Провода: XIAO D6 (GP0) → D+ синта, D7 (GP1) → D−, GND → GND. **VBUS не подключать** (синт работает от своей батареи). Если D+/D− перепутать — ничего не сломается, синт просто не определится.
- Синт полностью заряжен.
- Прошивка Transporter: https://github.com/kurogedelic/FM-1-transporter (форк с записью по секторам: https://github.com/ioneng/FM-1-transporter-RP2040-Zero). Гайд: https://github.com/Quixotic7/MvaveFM1Unbricker/blob/main/TRANSPORTER-GUIDE.md
- Для сборки прошивки XIAO: pico-sdk 2.2.0, ARM GCC, CMake, picotool; файл `wl82loader.bin` берётся из https://github.com/kagaimiq/jl-uboot-tool. Собрать и проверить — заранее, без синта.

## Шаги (только чтение)
1. Синт выключен. XIAO с прошивкой Transporter подключён к компьютеру, консоль XIAO открыта.
2. Включить синт, только когда скрипт попросит. Успех рукопожатия: строка вида `OK key=980F type=3 id=856014`.
3. `python3 tools/fm1t.py info` — только читает.
4. `python3 tools/fm1t.py dump backup1.bin`, затем `dump backup2.bin` (или в гайде Quixotic7: `fm1_transporter_recover.py dump backups --v15 FM-1.fwsc` — читает 1 MiB дважды и сравнивает).
5. Сравнить SHA-256 двух файлов: должны совпасть, размер ровно 1 048 576 байт.
6. Хранить в двух местах (диск + облако/флешка). В дампе пользовательские песни и настройки синта.
7. Выключить и снова включить синт перед обычной работой по USB.

## Нельзя
- Команды записи (`write --write`, `restore` со словом WRITE, `repair-settings` — последний стирает песни и настройки).
- Писать ниже 0x4000 (загрузчик). Восстановление пишет только 0x4000..0x92FFF.
- Включать синт до того, как консоль XIAO читается (рукопожатие зависает).

## Потом: проверка отката на V15 (один раз, до нашей прошивки)
- Файл `FM-1.fwsc` (PC Firmware V15) с https://www.m-vave.com/product?id=fm-1 (или https://www.m-vave.com/download).
- Официальный Windows-апдейтер M-UPGRADE по USB-MIDI, либо веб-установщик с проверкой SHA-256 (https://github.com/jadamsowers/fm1-fimba).
- Полный возврат из дампа: Transporter `write --package FM-1.fwsc --ref backup.bin --write` (пишет 0x4000..0x92FFF с проверкой), только если откат обычным путём не удался.

## Справка
- Референсный дамп V15 (другого синта): https://github.com/jvitkauskas/fm1-backup (1 048 576 байт, прошивка 015) — сравнивать только заголовок, не весь файл.
- AL-255/FM-1-RE: доказанного безопасного отката при обрыве записи нет; банк прошивки один.
