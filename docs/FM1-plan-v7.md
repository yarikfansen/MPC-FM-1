# FM-1 custom: план v7

22.10.2026. Заменяет план v6 в части объёма работ. Порядок работы прежний: список → вопросы → веб-образец → устройство.

## 1. Разбор ошибок: что случилось с первым FM-1

### Факты
- Прошита сборка из коммита **861b980** (18.10, 22:28). Исходники на ПК (`<work>/fm1_open\app`) побайтно совпадают с этим коммитом.
- Размер программы: **483 676 из 486 689 байт**, свободно около 3 КБ.
- В `build.log` пять предупреждений: **«toolchain revision differs from the SDK reference»** (clang, llvm-ar, llvm-objcopy, LLVMgold, pi32v2-ld). README требует JieLi PI32v2 clang **4.0.1 r3**, а стоит другая ревизия.
- В `firmware-report.json`: **`"board_validation": "not performed"`**. Сборка ни разу не проверялась на железе по частям.
- Пакет обновления пишет весь 1 МБ флеша: программу, настройки (VM), Bluetooth и **пользовательскую область 503 808 байт** (проекты и сэмплы) в самом конце.
- Прошивка встала на 95–97 %. После этого синт перезагружался примерно раз в секунду (щелчок, мигание экрана), USB не появлялся, UBOOT по OCT−/OCT+ не открывался.
- В `fm1_open` **нет защиты загрузки**: ни счётчика неудачных стартов, ни безопасного режима, ни входа в обновление по кнопке при включении.

### Вероятная причина (не доказана)
Программа, скорее всего, записалась целиком: она идёт в начале пакета, а 95 % приходится на пользовательскую область в конце. Дальше она запускалась и падала при старте, сторожевой таймер её перезапускал, и USB не успевал подняться. Поэтому ни один установщик не видел устройство.

Возможные причины падения, по убыванию вероятности:
1. Чтение недописанной пользовательской области при старте (проекты, строй, наш сектор extras стоят в самом хвосте флеша).
2. Новый код на пути старта: extras, библиотека звуков, изменения буферов эффектов в прерывании звука (коммиты 79685b3, c05f051, 3d80964).
3. Компилятор не той ревизии.

Проверить можно только дампом флеша первого синта через Transporter.

## 2. Как не сломать второй FM-1

Риск ноль не бывает. Но можно добиться того, что любую поломку можно откатить к точной копии этого синта.

1. **В первый день ничего не прошивать.** Зарядить, поиграть на стоковой прошивке, записать версию.
2. **Собрать Transporter** (Seeed XIAO RP2040, D+ → D6, D− → D7, GND → GND, VBUS не подключать). На **исправном** синте проверить вход в UBOOT и снять **полный дамп флеша** только на чтение. Хранить в двух местах.
3. **Проверить путь назад:** один раз переустановить официальную V15 официальным установщиком.
4. **Починить компилятор:** поставить ровно clang 4.0.1 r3, чтобы предупреждений о ревизии не было. Собрать **немодифицированный** FM1 Open, прошить, убедиться, что работает.
5. **Первая наша правка — защита загрузки**, как у семейства Felucca (FiMba, sloop, X0X, Melodee):
   - счётчик неудачных стартов; после 2 подряд — безопасный режим: без звука, без чтения проектов, USB включён;
   - OCT− при включении — сразу режим обновления по USB;
   - старт считается удачным только через несколько секунд нормальной работы;
   - до этого момента пользовательская область не читается; все записи проверяются по CRC, при сбое — значения по умолчанию.
6. **Пакет без пользовательской области**, если установщик это позволяет. Если нет — сначала резервная копия проектов.
7. **Запас по месту не меньше 16 КБ.** Пиковая нагрузка звука в симуляторе ниже 70 %.
8. **Перед каждой прошивкой:** нативные тесты, фаззинг эффектов под ASan/UBSan, веб-симулятор.
9. **Условия прошивки:** полная батарея, кабель с данными напрямую в ПК без хаба, закрыть программы и вкладки с MIDI, синт не трогать.
10. **Одна правка — одна прошивка.** Хранить последний рабочий `.fwsc`.

## 3. Объём v7

### Движки
- **Оставить:** DX7 (FM, колокола, металл, EP), CHIPTUNE (PSG).
- **Добавить:** ANALOG — 4 осциллятора, режимы MONO / POLY / UNISON. В POLY 4 голоса по 2 осциллятора, UNISON 2–4 голоса. Цифры проверить замером.
- **Убрать:** SAMPLER (и сэмплы), DRUM 808.
- **Открытые вопросы:** BASS 303 и PLUCK в списке не названы — убрать или оставить? Без 808 ударные будут только пресетами DX7, PSG и ANALOG (шум) — так и задумано?

### Звуки
- Один список пресетов по разделам. Раздел выбирается ручками K1–K4 и ставится при сохранении по той ручке, которой крутили.
- На дорожке звук выбирается одной ручкой, как сейчас.
- Лаборатория синтеза: DX7 / ANALOG / CHIPTUNE, у каждого своя страница.
- Звуки чиптюна живут в разделе лидов.

### Интерфейс
- Главный экран — микшер и секвенсор вместе.
- HOME: тап — назад, удержание — главный экран. **Сделано** (коммит a90d5bb, не прошито).
- Осциллограф убран. **Сделано** (a90d5bb).
- Удобные арпеджиатор и секвенсор; хороший звук и эффекты.
- Удалить страницы, которые ни одна кнопка не открывает: MIX, PRESET BROWSER, EFFECTS, FM LFO.

### Порядок
1. Безопасность (раздел 2): Transporter, дамп, компилятор, защита загрузки.
2. Чистка: сэмплер, 808, мёртвые страницы. Замер места.
3. Движок ANALOG и пресеты.
4. Главный экран микшер+секвенсор, лаборатория.
