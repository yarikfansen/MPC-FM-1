# Открытые базы для FM-1: сравнение и рекомендация (22.10.2026)

Метод: shallow-клоны в `<work>/eval\*`, README/LICENSING/BUILDING + точечный grep по коду. Ничего не прошивалось. Звук и нагрузку на железе не проверял (только заявления авторов).

## Главное
Все пять кандидатов — **одна семья**: форки Felucca (Hügelton). Это **полностью свой firmware** (свой HAL, USB, загрузчик обновлений, движки на C), он **не использует** закрытый `libfm1_engine.a`. Поэтому ограничение «нельзя добавить движок / 2,3 КБ флеша» исчезает. Цена: лицензия GPL-3.0 (наш код при переносе тоже станет GPL-3) и потеря официальных 303/808/сэмплера (они вам не нужны).

## Ответ на ключевой вопрос
**Да, перейти на открытую базу можно** — и два из трёх ваших пожеланий уже есть «из коробки»:
- **Нативный DX7** не нужно портировать: FM6 уже = msfa (Apache-2.0), как и наш `web/synth`. Работа сводится к сверке/замене `fm6_core.c` на целочисленную версию M-VAVE (если звук разнится) — Felucca/sloopDX целочисленные и сверены с Dexed, Melodee ушёл на float.
- **Своя защита**: `app/boot_guard.c` по смыслу совпадает с bootguard Felucca; у Melodee/X0X защита сильнее (stub с CRC; safe mode с USB). Наш journal-вариант можно оставить как дополнение, но проще принять stub Melodee.
- **VA «как Baud Girl»**: у Felucca ANALOG (sub-осц., POLY/MONO/LEG/UNI) — ближе всего к желаемому; у Melodee PROPHET богаче (8 голосов, unison, glide), но без sub-осциллятора.

## Рекомендация
**Основа — Melodee** (самая живая, есть boot-stub с CRC и OCT−-спасением, HOME-«сцена» с полосой на трек — родственна нашему mixer-home, FM6 с редактором и SysEx, песни/банки), плюс **вернуть из Felucca-Engines (MIT) движки ANALOG (sub-осц.) и LOFI (чип)** — их интерфейс `felucca_engine.h` общий, ID зарезервированы. **Запасной вариант — Felucca 1.6.1**: уже содержит ANALOG+LOFI+FM6 и 15 режимов арпы, но проект заморожен (багфиксов не ждать; стабильность известна). X0X берём только как образец safe mode; sloopDX — только как образец правки DX7 (узкий, один движок); JIANT — beta без проверки на железе.

Риск: Melodee обязательно на 2 ядрах, у части FM-1 были проблемы со стартом CPU1 (они это починили, но это новая поверхность отказа для пользователя, у которого уже окирпичен один аппарат). Поэтому **первым делом ставить на штатный запасной FM-1 только после дампа флеша и проверки отката на V15**, как в CLAUDE.md.

## Оценка трудозатрат (сессии, грубо)

## Сборка
Не пробовал: требует Linux-тулчейн (WSL/Docker, не установлены Docker и Pillow), клон AC79 SDK с gitee и Python Pillow — «крупные новые установки» кроме `C:\JL\pi32`. Тулчейн на ПК — Windows clang 4.0.1 (проверка `--version` OK, ревизия r3 надо сверить отдельно).

## Не проверено
Реальная ёмкость флеша/ЦПУ у баз (авторы не публикуют цифр); качество звука ANALOG/PROPHET; отличие float-FM6 от M-VAVE DX7 на слух. Клоны в `<work>/eval` (shallow, submodule `firmware/engines` у Felucca пуст — тянуть при сборке).
